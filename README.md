Saya adalah seorang siswa kelas X jurusan **Teknik Komputer dan Jaringan (TKJ)** di **SMK Negeri 2 Lamongan** yang memiliki ketertarikan besar pada bidang jaringan komputer, perakitan perangkat keras, dan desain grafis digital.

## Keahlian
- Perakitan Komputer & Troubleshooting Hardware
- Instalasi & Konfigurasi Jaringan Dasar (LAN/WLAN)
- Desain Grafis & Pengolahan Visual Digital
- Pengembangan Web Dasar (HTML & CSS)

## Proyek & Praktikum Unggulan
- **Portofolio Web dengan GitHub Pages:** Tugas praktik membuat halaman portofolio online menggunakan GitHub untuk mempelajari dasar web dan Cloud Computing.
- **Simulator Virtual Lab TKJ:** Simulasi interaktif pengecekan komponen dasar jaringan dan skema pengkabelan (Crimping Kabel UTP).
